# rec·ording · descargas

Graba tu móvil Android y conviértelo en un vídeo promocional con marco, fondo y zooms suaves.

**Descarga la última versión en https://blzkz.github.io/rec-ording-releases/**

Hay paquetes para Windows, Debian/Ubuntu (.deb), Fedora/openSUSE (.rpm), Arch Linux y AppImage para cualquier otra distribución. Una vez instalada, la app avisa cuando hay una versión nueva y la instala sola.
