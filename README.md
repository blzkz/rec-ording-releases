# rec·ording · descargas

Graba tu móvil Android y conviértelo en un vídeo promocional con marco, fondo y zooms suaves.

Aquí se publican las versiones de la app. La app comprueba este repositorio al abrirse y avisa cuando hay una nueva.

## Instalar

En [Releases](https://github.com/blzkz/rec-ording-releases/releases/latest) está la última versión.

- **Arch Linux / CachyOS**: descarga `rec-ording-<versión>-1-x86_64.pkg.tar.zst` e instálalo con
  `sudo pacman -U rec-ording-<versión>-1-x86_64.pkg.tar.zst`
- **Windows**: descarga `rec-ording-<versión>-windows-x64.zip`, descomprímelo y abre `rec-ording.exe`
  (lee `LEEME.txt` para instalar ffmpeg, adb y scrcpy).

Las siguientes versiones se instalan desde la propia app.
