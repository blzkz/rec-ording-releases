Novedades

  • Nueva página de descargas: todas las versiones se descargan desde aquí, con el paquete de cada sistema y su suma de comprobación.
  • Galaxy S26 Ultra incluido: es el único modelo 3D que trae la app. Modelo «Samsung S26 Ultra» de Sagar Modi en Sketchfab, licencia CC BY 4.0: menciona al autor al publicar tus vídeos.
  • Aviso de actualización: al abrir la app, si hay una versión nueva, aparece una ventana para instalarla.
  • Emulador de Android: puedes grabar un emulador de Android Studio igual que un móvil por USB, con sus toques y zooms automáticos.
  • Más distribuciones de Linux: paquetes para Debian/Ubuntu (.deb), Fedora/openSUSE (.rpm) y AppImage para cualquier otra, además de Arch y Windows.

Antes de empezar

Para importar y exportar vídeos hace falta ffmpeg; para grabar el móvil o un emulador, adb y scrcpy. Los paquetes .deb, .rpm y de Arch los instalan o recomiendan; con el AppImage y en Windows se instalan aparte.

Una vez instalada, la app avisa cuando hay una versión nueva y la instala sola.

El modelo 3D incluido, «Samsung S26 Ultra», es de Sagar Modi (Sketchfab), con licencia CC BY 4.0.
